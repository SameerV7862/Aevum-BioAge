# Feature-to-BioAge Mapping (Draft)

## Purpose
Map exercise/gameplay features to interpretable aging-related constructs.

## Mapping table (initial)
- `total_valid_reps` -> muscular endurance capacity
- `hold_duration_max` -> isometric endurance / control
- `cadence_cv` -> neuromotor consistency
- `prompt_latency_mean` -> reaction and control speed proxy
- `rom_consistency_score` -> movement quality stability
- `fatigue_slope` -> endurance decay profile

## Guidance
Each mapping requires literature-backed rationale and confidence grading:
- High confidence
- Moderate confidence
- Exploratory

## Output behavior
Low-confidence feature sets should widen confidence intervals and lower reliability label.
